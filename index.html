⚙️ Multi-Language Architecture & Core Engines

CarePill utilizes a multi-disciplinary software architecture combining HTML5, CSS3, JavaScript, Java, C++, and Python. Every language fulfills a critical responsibility in this healthcare system:

🌐 1. Frontend Web Layer (HTML5, CSS3, JavaScript)

Provides an elderly-centric UI with high-contrast accessibility (WCAG compliant), Web Speech API for voice assistance, and Web Audio API for harmonic cues.

🐍 2. Data & Adherence Analytics (Python 3)

Located in python/adherence_analytics.py. Analyzes 7-day adherence patterns, calculates statistical risk for missed doses, and generates medical export reports.

⚡ 3. High-Performance Schedule Optimizer (C++ 17)

Located in cpp/schedule_optimizer.cpp. Employs conflict-resolution algorithms to ensure dangerous drug combinations have safe timing separation intervals.

☕ 4. Object-Oriented Scheduler Service (Java 17)

Located in java/MedicationScheduler.java. Provides robust enterprise OOP models for dosages, schedule slots, recurring reminder triggers, and caregiver notification payloads.

Python Engine (python/adherence_analytics.py) - Computes compliance rates and risk metrics:

def calculate_adherence(medication_history: list) -> dict:
    total_scheduled = len(medication_history)
    taken_on_time = sum(1 for entry in medication_history if entry.get("status") == "TAKEN")
    adherence_rate = (taken_on_time / total_scheduled) * 100 if total_scheduled > 0 else 0.0
    return {
        "total_scheduled": total_scheduled,
        "taken_on_time": taken_on_time,
        "adherence_percentage": round(adherence_rate, 2),
        "status": "EXCELLENT" if adherence_rate >= 85 else "NEEDS_ATTENTION"
    }

C++ Engine (cpp/schedule_optimizer.cpp) - Detects drug interaction conflicts:

struct MedicationConflictChecker {
    bool hasInteractionConflict(const std::string& medA, const std::string& medB) {
        // High-performance hash lookup for known dangerous combinations
        static const std::unordered_set<std::string> conflictPairs = {
            "aspirin+warfarin", "warfarin+aspirin",
            "ibuprofen+aspirin", "aspirin+ibuprofen"
        };
        std::string key = toLower(medA) + "+" + toLower(medB);
        return conflictPairs.find(key) != conflictPairs.end();
    }
};

Java Engine (java/MedicationScheduler.java) - Object-oriented domain model:

public class MedicationScheduler {
    public static class DoseRecord {
        private String medicineId;
        private LocalDateTime scheduledTime;
        private boolean isTaken;

        public DoseRecord(String medicineId, LocalDateTime scheduledTime) {
            this.medicineId = medicineId;
            this.scheduledTime = scheduledTime;
            this.isTaken = false;
        }

        public void markTaken() { this.isTaken = true; }
        public boolean isOverdue() {
            return !isTaken && LocalDateTime.now().isAfter(scheduledTime.plusHours(1));
        }
    }
}
